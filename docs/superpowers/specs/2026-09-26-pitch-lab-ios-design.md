# Pitch Lab iOS 设计规格

## 目标

实现一个以“比的原理”网站音乐工具为灵感的原生 iPhone App。首版提供实时测音高、虚拟钢琴、绝对音高听音测试。界面和文案独立设计，不复制网站素材。

## 平台与交付

- SwiftUI、AVFoundation；最低 iOS 17。新增乐谱练唱功能使用 ZIPFoundation 读取 MXL，详见同目录的乐谱练唱规格。
- 在 GitHub Actions 的 macOS runner 上编译和运行测试。
- 产出未签名的 `.ipa` 和构建日志；用户负责签名。签名后才能安装到 iPhone。
- 本地 Windows 环境无法运行 Xcode；最终设备音频体验需在 iPhone 验证。

## 功能

### 实时测音高

- 用户授权麦克风后，连续显示最近稳定的人声音高：音名、八度、Hz、相对最近半音的音分偏差。
- 绘制最近约 10 秒的音高曲线。无稳定音高时显示等待状态，不保留误导性的旧读数。
- 支持开始、暂停和重试授权。输入只在设备内分析，不上传、不保存录音。
- 使用 AVAudioEngine 采样，DSP 模块从音频帧估算基频，排除低能量和明显无效结果；音符转换单独实现。

### 钢琴

- 提供 C3 至 B5 的可滚动琴键。按下播放、松开停止，支持同时按多个键。
- 用本地合成音发声，不依赖网络或第三方音频资源；展示音名和八度。

### 听音测试

- 从 C4 至 B5 随机挑选音符并播放。用户在 12 个音名中选择，默认不即时揭示答案。
- 一轮 10 题，完成后显示正确数、正确率、逐题答案；可重新开始。
- 测试页说明：使用钢琴或其他参考音会影响“绝对音高”测试的解释；分数仅反映这轮辨音表现。

## 界面

底部三个标签：测音高、钢琴、听音测试。测音高页以大号音名和偏差刻度为中心，曲线位于下方。深浅色模式均可用。麦克风权限被拒绝、音频会话启动失败和音频输出不可用时显示具体状态与重试操作。

## 架构

- `PitchDetector`：音频帧到基频及置信度。
- `NoteMath`：频率、MIDI 音符、音名与音分转换。
- `MicrophonePitchService`：音频采集、节流、状态发布。
- `TonePlayer`：标准音合成与播放。
- `PitchViewModel`、`QuizViewModel`：页面状态与操作。
- SwiftUI 视图只负责交互和绘制。

## 验收

- 音符数学和听音计分有自动化测试。
- GitHub Actions 在 iOS Simulator 目标上完成构建和单元测试，随后打包未签名 IPA 并上传 artifact。
- 真机手工检查麦克风授权、稳定音检测、钢琴多点触控、后台切换和音频中断恢复。
