# PitchLab App Store 首发规格

## 产品
- 免费下载。用户确认开启后可完整使用 7 天（自已验证的试用交易时间起算 168 小时），到期不自动扣费。
- 设两个 StoreKit 2 非消耗型商品：零价「7-day Trial」和「永久解锁 / Lifetime Unlock」。国区买断 ¥1；其他地区按当地商店显示 StoreKit 返回的价格。永久解锁包含后续更新和新增功能，无续费、无额外付费档。
- 使用 Apple 验证交易确定权益。支持同一 Apple 账号恢复、换机和重装；已验证权益可离线使用，不因临时断网清除。未确认购买、取消及退款不能授予永久权益。试用时间不以首次启动或重装重置。
- 到期仍可查看已导入的乐谱和已有记录、访问恢复购买、隐私和反馈；限制新的练习。练习过程中到期须安全结束麦克风会话，已有资料保留。
- 反馈放在「关于与设置」，打开邮件草稿，由用户自行发送，不附加录音、乐谱或设备日志。无邮件客户端时支持复制反馈地址。发布时使用用户提供的公开支持邮箱。
- 首发简体中文、英文；按系统语言选择，其他语言回退到英文。覆盖错误提示、麦克风权限、购买与反馈界面，以及中英商店文案和截图。导入的内容保持原样。

## 构建与送审
- 在现有 SwiftUI 工程增加权益模块，保留 iOS 17 最低系统版本；构建使用符合 Apple 当前要求的 Xcode/SDK。现有未签名测试包流程和 App Store 分发包流程分开。
- 准备隐私政策和支持页、应用图标、示例乐谱、审核步骤及隐私申报核对表。按照实际数据处理核对隐私清单及依赖，不在文案中预先声称未核验的隐私属性。
- App 与两个内购商品均以覆盖所有可用地区为目标；地区限制按 App Store Connect 显示的要求处理。账号持有人负责签署协议、核验身份及提供地区材料。
- 测试试用起止、恢复、待处理、取消、退款、断网、到期保留资料，以及中英界面。通过 GitHub macOS 测试后，在 TestFlight 用真机验证购买和练唱，再提交审核。
- 此规格不授权公开发布、修改实际商店价格或代签苹果协议。准备好可核验的送审版本和资料后，再由账号持有人处理上述操作。
