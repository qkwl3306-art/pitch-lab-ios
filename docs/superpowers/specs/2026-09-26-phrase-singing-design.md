# 人声乐谱逐句练唱设计

## 目标与范围

在现有 iOS 17+ SwiftUI 应用的「练唱」页增加可导入的人声旋律、单独歌词、逐句纠错和个人音域推荐。用户提供的 SVP 与 MIDI 样例均含 260 个 C♯3–C♯5 人声音符；SVP 的歌词全为 `la`，MIDI 的旋律轨名为 `Vocal` 且没有歌词。因此两种旋律文件和歌词文件必须能分别导入。现有 PDF、照片、MusicXML/MXL 和 ±12 半音移调继续可用。

## 导入与数据

- `.svp`：读取 JSON 中首个包含歌唱音符的人声轨，包含 `mainGroup` 的 onset、duration、pitch、lyrics 与 tempo map。将 SVP blick（每四分音符 705600000）换算为秒；应用 `mainRef` 的时间与音高偏移。无法识别的版本、空轨或无效时值给出明确错误，不静默生成空乐谱。
- `.mid`／`.midi`：读取标准 MIDI 文件的头、变长时间、轨道、tempo、note on/off 和 track name。优先选择名为 `Vocal` 的非空旋律轨；否则让用户选择有音符的轨道。拒绝损坏文件，忽略非音符事件。将 tick 换算为秒。
- 统一保存每个音的目标 MIDI 音高、开始时间、持续时间、可选音节和来源轨道。原文件留在应用私有目录；更新现有清单格式时兼容已导入乐谱。
- `.lrc`：解析标准时间戳与歌词，按时间映射到最近乐句；`.txt`：一行对应一句。也可直接粘贴歌词。允许编辑每句文字与关联，避免自动对应错误。`.lysc` 样例是未公开的专有二进制格式，首版通过来音制谱可导出的 SVP/MIDI 路径使用该乐谱，不承诺直接解析 `.lysc`。PDF 与图片继续只作看谱使用，不自动生成音高目标。应用内 MP3 自动扒谱不在本次范围。

## 分句与练习

- 按相邻音符之间至少两个四分音符的空隙自动分句；过长乐句在小节附近切分。用户可调整相邻乐句边界。展示歌词（若有）、音高轨道、音符名和目标音高曲线。
- 选择一句后可先播放示范旋律。点击「开始」后显示倒数并录入麦克风音高；示范音在录入期间停止。将每次有声帧按练习起点和谱面时间映射到目标音符，忽略音符起止两端短暂换音区间。
- 每个音需要足够有声覆盖，且大多数有效帧在目标音 ±50 音分内才算达标。显示达标、偏高、偏低、漏唱，标出具体音符和偏差；一整句所有音都达标才通过，否则可以只重练本句。保留每句最近一次结果和尝试次数；用户可手动重试或跳到其他句。
- 音高检测和反馈均在设备端进行，不上传录音；本版保存分数与音准概要，不保存原始录音。耳机可减少示范音串入麦克风，但练习不依赖耳机。

## 个人音域与推荐调

- 提供引导测试：分别持续唱舒适的最低音和最高音，各取稳定音高的中位数；允许手动修正并保存在设备上。界面说明这是舒适音域，不能用短暂勉强发出的极限音冒充。
- 对整首人声旋律枚举 -12 到 +12 半音，优先最大化落入舒适音域的音符比例，再优先增加旋律上下两端的余量，最后优先选择移调幅度较小者。显示推荐移调、原调与推荐调的覆盖率、最高／最低目标音；若任何调都无法完全覆盖，明确显示超出范围的音符数。
- 采用建议调时更新逐句目标音与示范音，清除旧调的练习成绩，避免混用。

## 界面与错误处理

「练唱」乐谱库增加 SVP/MIDI/歌词导入入口。人声乐谱详情依次显示歌曲音域、推荐调、乐句列表和当前乐句练习页。歌词缺失时显示「第 N 句」与音符，不阻止练习。文件损坏、无 Vocal 轨、无法识别歌词时间戳、麦克风权限不足均给出可恢复的提示。

## 验证

- 使用用户提供的 SVP/MIDI 文件验证 260 个音符、C♯3–C♯5 音域与时间顺序；用构造的小样例测试变速、休止、歌词映射、损坏文件和旧清单迁移。
- 用确定的音高帧序列测试逐音覆盖率、偏高／偏低、漏唱、整句通过与重试；测试推荐调的覆盖率和边界。
- GitHub macOS 模拟器执行乐谱导入、练唱入口与主要控制的 UI 测试，上传截图；构建设备版未签名 IPA。真实 iPhone 上的麦克风和音频路由仍由用户安装后复测。
